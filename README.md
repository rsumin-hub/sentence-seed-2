# 문장씨앗 2.0 알파

기존 문장씨앗과 별도로 시험하는 새 프로젝트입니다.

## 현재 구현
- React + Vite 기반 PWA
- IndexedDB 저장
- 책 표지 자동 압축
- 페이지 사진 자동 압축
- 한국어·영어 OCR
- OCR 결과 문장별 선택
- 생각·내 문장·활용처·태그·실천 기록
- 검색
- JSON 백업·복원
- 아이폰 홈 화면 설치

## 아직 포함되지 않은 기능
- 회원 로그인
- 여러 기기 자동 동기화
- AI 인사이트
- 블로그·강의안 자동 생성

## 배포 방법
1. GitHub에 새 저장소 `sentence-seed-2`를 만듭니다.
2. 이 ZIP의 압축을 풀고 안의 파일 전체를 업로드합니다.
3. Vercel에서 Add New → Project → `sentence-seed-2` Import
4. Vite로 자동 인식되면 Deploy를 누릅니다.
5. 생성 주소를 아이폰 Safari에서 열고 공유 → 홈 화면에 추가합니다.
