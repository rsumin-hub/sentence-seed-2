문장씨앗 2.0 alpha.2

수정 내용
- 문장촬영기록에서 '사진 촬영'과 '사진첩에서 선택' 버튼을 분리했습니다.
- 아이폰에서 카메라만 열리던 문제를 수정했습니다.
- 두 방식 모두 선택 후 같은 OCR 기능을 사용합니다.

업데이트 방법
1. ZIP 압축을 풉니다.
2. GitHub의 sentence-seed-2 저장소로 이동합니다.
3. Add file → Upload files
4. 압축을 푼 폴더 안 파일 전체를 업로드합니다.
5. Commit changes
6. Vercel 자동 배포 완료 후 아이폰 Safari에서 새로고침합니다.
7. 홈 화면 앱을 완전히 종료하고 다시 실행합니다.
